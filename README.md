# Anki ハンズフリー

AnkiDroid のカードを **読み上げ** て、画面いっぱいの **大きなボタン** で評価できる Android アプリです。
散歩中・通勤中など、画面をじっと見たり声を出したりせずに Anki の復習を進められます。

学習データは AnkiDroid 本体に保存されるため、スケジュール（FSRS / SM-2）や AnkiWeb 同期はそのまま使えます。

## 使い方

1. AnkiDroid をインストールし、コレクションを用意する
2. このアプリを起動し、「AnkiDroid のデータへのアクセス」を許可する
3. デッキを選んで「学習を開始」
4. 表面が読み上げられたら思い出し、**画面のどこかをタップ** するか **音量ボタン** を押す → 答えを読み上げ
5. 答えを聞いたら評価する

学習画面は、上部にカードの文字を小さく表示し、残りの画面全体がタップ領域です。

```
┌───────────────────────┐
│ 学習済み 12 枚  🔁 ⏹  │
│ apple / りんご        │  ← カードの文字（確認用）
├───────────┬───────────┤
│           │           │
│ もう一度  │   正解    │  ← 大きい（音量 − / 音量 ＋）
│           │           │
├───────────┼───────────┤
│  難しい   │   簡単    │  ← 小さめ
└───────────┴───────────┘
```

### 音量ボタン

| | 音量 ＋ | 音量 − |
| --- | --- | --- |
| 問題のとき | 答えを見る | 答えを見る |
| 答えのとき | 正解 | もう一度 |

- 押すと振動するので、画面を見なくても押せたか分かります。
- 学習中は音量ボタンで音量が変わりません（設定で OFF にできます）。
- 長押しのキーリピートは無視するので、押しっぱなしで何枚も進むことはありません。
- 画面がオンのとき（アプリを開いているとき）だけ使えます。

### その他

- ボタンは読み上げ中でも押せます（押すと読み上げを止めてすぐ進みます）。
- 「評価を読み上げて確認する」を ON にすると、押した評価（「正解」など）を読み上げます。
- 「🔁 再読」で再読み上げ、「⏹ 終了」で学習を終えます。
- 前のカードで連打した分は次のカードに持ち越されません。

### 設定

- 問題 / 答えそれぞれの読み上げ言語（例: 問題は英語、答えは日本語）
- 読み上げ速度
- 操作しなければ自動で答えを読み上げる（考える時間 2〜20 秒）
- 音量ボタンでの操作 ON/OFF
- 評価の読み上げ確認 ON/OFF
- **音声コマンドも使う**（既定は OFF。ON のときだけマイクの許可を求めます）

### 音声コマンド（任意）

設定で ON にすると、ボタンに加えて声でも操作できます。

| 話しかける言葉（例） | 動作 |
| --- | --- |
| 「答え」「次」「めくって」/ "answer" | 裏面を読み上げる |
| 「もう一度」「わからない」「1」/ "again" | もう一度 |
| 「難しい」「微妙」「2」/ "hard" | 難しい |
| 「正解」「わかった」「3」/ "good" | 正解 |
| 「簡単」「楽勝」「4」/ "easy" | 簡単 |
| 「繰り返して」「もう一度読んで」/ "repeat" | 再読み上げ |
| 「終了」「ストップ」/ "stop" | 学習を終える |

## 仕組み

```
AnkiDroid ──(ContentProvider: com.ichi2.anki.flashcards)──▶ AnkiDroidRepository
                                                            │ 次のカード / 回答送信
TextToSpeech ◀── Speaker ◀── ReviewViewModel（学習ループ）◀── 画面の大きなボタン
                                     │
                                     └──（任意）SpeechListener ──▶ VoiceCommandParser
```

| ファイル | 役割 |
| --- | --- |
| `anki/AnkiDroidRepository.kt` | AnkiDroid API でデッキ一覧・次のカード・カード本文を取得、回答を送信 |
| `anki/CardText.kt` | カード HTML を読み上げ用テキストに変換（style・音声タグ・ふりがな・穴埋め対応） |
| `voice/Speaker.kt` | TextToSpeech の suspend ラッパー |
| `voice/SpeechListener.kt` | SpeechRecognizer の suspend ラッパー（音声コマンド ON のときのみ使用） |
| `voice/VoiceCommand.kt` | 認識結果の文字列を学習コマンドに変換（日本語・英語） |
| `review/ReviewViewModel.kt` | 出題 → 読み上げ → 聞き取り → 評価 のループ |
| `ui/MainScreen.kt` | Jetpack Compose の画面（大きな評価ボタン・設定） |

## ビルド

- Android Studio (Ladybug 以降) で開いて実行
- またはコマンドラインで `./gradlew assembleDebug`
- テスト: `./gradlew test`

要件: minSdk 26 (Android 8.0) / targetSdk 35 / AnkiDroid 2.x 以降
